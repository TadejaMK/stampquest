# Stamp Quest

Take one photo every day and turn it into your own digital stamp.

**Live site:** https://stampquest.netlify.app/

## Features

- Create an account and log in
- Take one photo each day and turn it into a digital stamp
- Build up your own collection of stamps over time

## Getting started

1. Open https://stampquest.netlify.app/
2. Click **Get Started** to register, or **Login** if you already have an account.
